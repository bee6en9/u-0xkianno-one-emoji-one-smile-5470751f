One emoji, one smile: this program writes exactly one emoji — 😁 (U+1F601,
BEAMING FACE WITH SMILING EYES) — to `/output/entry.txt`, the emoji most
likely to make a stranger smile.

[One Emoji, One Smile on make.fun](https://make.fun/bounty/u-0xkianno-one-emoji-one-smile-5470751f)

## Why 😁

A wide, genuine grin with smiling eyes: warm at first glance, universal
across ages and backgrounds, clearly chosen (not the default 🙂 or 😊), and
right for a stranger — pure friendliness, no hug, no hearts, no irony.

## Run

```sh
node main.ts   # Node 22+
```

Deterministic, no network, no dependencies. Writes exactly one emoji
(1 character, 4 bytes UTF-8) to `/output/entry.txt`.

Play code: `vfk2n47z`
